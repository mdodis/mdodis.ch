My Homelab

Unfortunately (or fortunately, depending on who you ask), I don't happen to have a huge amount of space available to store huge server racks. But I believe I've done well with what I have available.


I run Debian on a second hand Lenovo ThinkCentre M700 (mine also includes a CD/DVD bay). On it I've connected a budget DAS housing second hand HDDs for long-term storage (I'm not really concerned about RW speed, but mostly ease of use and practicality). I control it with some cheap wireless usb-remote pad (for which I will not bother fishing for the exact model and make; they're all very similar).


When the server is on, I use a samba service which I configured on LAN, so that I don't have to wire up cables to do transfers... And that's about it!

Oh by the way: I found out that you can put shortcuts in "%appdata%\Microsoft\Windows\Network Shortcuts", and that will show up quite convenietly under "This PC" in the file explorer. So instead of trying to use the network tab, you can have a shortcut to take you straight to the server files through SAMBA, or open an SSH session without having to bother much. Neat!

Open Solomon's Key

Open Solomon's Key is an open-source remake of the 1986 arcade game by Tecmo. It tries to be truthful to the original game (as much as anyone can without the original source code), while adding some extra elements, like a fully customizable level format.
